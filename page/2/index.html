各種 Normalization 介紹

發表於 2026-03-09 更新於 2026-08-16

什麼是 Normalization？

Normalization 是深度學習中常用的一種技術，用於標準化神經網絡中的數據分布。它可以加速模型訓練、提高模型穩定性，並在某些情況下提升模型性能。

用另一種方式來說明，假設你有1000張黑狗的圖片，你要讓模型學習分辨圖片是黑狗的圖片，而不是白狗、貓…等。
而此時，會發現雖然這些圖片都是黑狗，但每張圖片的背景、光線、角度…等都不一樣，這些因素會影響模型的學習效果。
Normalization 就是用來解決這些問題的技術，通過對數據進行標準化，使得模型能夠更好地學習到黑狗的特徵，而不受其他因素的干擾。
而這些事情都是在向量空間中進行的，實際上標準化是透過數學公式取得這1000張圖片的平均值和標準差。

為什麼需要 Normalization？

在深度神經網絡的訓練過程中，每一層的輸入分布會隨著前面層的參數更新而不斷變化，這種現象稱為「內部協變量偏移」（Internal Covariate Shift）。Normalization 技術通過標準化每一層的輸入，可以：

  1. 加速訓練：減少內部協變量偏移，使得模型能夠使用更大的學習率
  2. 提高穩定性：降低梯度消失和梯度爆炸的風險
  3. 正則化效果：某些 Normalization 方法具有一定的正則化作用，可以減少過擬合

常見的 Normalization 方法

1. Batch Normalization (BN)

Batch Normalization 是最常用的正規化方法之一，由 Ioffe 和 Szegedy 在 2015 年提出。

工作原理：

  • 對每個 mini-batch 中的數據，在每個特徵維度上計算均值和方差
  • 使用這些統計量來標準化數據
  • 引入可學習的縮放參數 γ 和偏移參數 β

公式：

x^=x−μBσB2+ϵ\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} x^=σB2​+ϵ​x−μB​​

y=γx^+βy = \gamma \hat{x} + \beta y=γx^+β

適用場景：

  • CNN 中使用廣泛
  • batch size 較大時效果較好
  • 訓練和推理階段行為不同（推理時使用移動平均的統計量）

優點：

  • 顯著加速訓練
  • 允許使用更大的學習率
  • 降低對初始化的敏感度

缺點：

  • 對 batch size 敏感，batch size 太小時效果不佳
  • 在 RNN 等序列模型中使用較困難

2. Layer Normalization (LN)

Layer Normalization 由 Ba 等人在 2016 年提出，主要用於解決 Batch Normalization 在小 batch size 和序列模型中的問題。

工作原理：

  • 對每個樣本的所有特徵維度計算均值和方差
  • 不依賴 batch size，在每個樣本內部進行標準化

公式：

x^=x−μLσL2+ϵ\hat{x} = \frac{x - \mu_L}{\sqrt{\sigma_L^2 + \epsilon}} x^=σL2​+ϵ​x−μL​​

y=γx^+βy = \gamma \hat{x} + \beta y=γx^+β

適用場景：

  • RNN、LSTM、Transformer 等序列模型
  • batch size 較小的情況
  • 強化學習

優點：

  • 不受 batch size 影響
  • 訓練和推理階段行為一致
  • 適合序列模型

缺點：

  • 在某些 CNN 任務中效果可能不如 Batch Normalization

3. Instance Normalization (IN)

Instance Normalization 由 Ulyanov 等人在 2016 年提出，主要用於風格遷移任務。

工作原理：

  • 對每個樣本的每個通道分別計算均值和方差
  • 在空間維度上進行標準化

適用場景：

  • 圖像風格遷移
  • 圖像生成任務（GAN）
  • 不希望不同樣本之間相互影響的場景

優點：

  • 適合處理單個樣本的風格信息
  • 對 batch size 不敏感

缺點：

  • 在一般的分類任務中效果不如 Batch Normalization

4. Group Normalization (GN)

Group Normalization 由 Wu 和 He 在 2018 年提出，作為 Batch Normalization 的替代方案。

工作原理：

  • 將通道分成多個組
  • 在每個組內計算均值和方差
  • 是 Layer Normalization 和 Instance Normalization 的推廣

適用場景：

  • batch size 較小的情況
  • 目標檢測、圖像分割等任務
  • 替代 Batch Normalization

優點：

  • 不受 batch size 影響
  • 在小 batch size 時效果優於 Batch Normalization
  • 在計算機視覺任務中表現良好

缺點：

  • 需要選擇合適的分組數量

各種 Normalization 的比較

方法 標準化維度 Batch Size 敏感度 主要應用場景
Batch Normalization 跨 batch 樣本 高 CNN、大 batch size
Layer Normalization 跨特徵維度 低 RNN、Transformer
Instance Normalization 單個樣本的單個通道 低 風格遷移、GAN
Group Normalization 通道分組 低 小 batch size、檢測任務

如何選擇 Normalization 方法？

  1. CNN + 大 batch size：優先選擇 Batch Normalization
  2. RNN、Transformer 等序列模型：選擇 Layer Normalization
  3. 小 batch size 的計算機視覺任務：選擇 Group Normalization
  4. 風格遷移、圖像生成：選擇 Instance Normalization
  5. 強化學習：選擇 Layer Normalization

實踐建議

  1. 初始選擇：對於大多數 CNN 任務，先嘗試 Batch Normalization
  2. 調整位置：Normalization 層通常放在卷積層之後、激活函數之前
  3. 微調參數：注意調整 momentum 參數（用於計算移動平均）
  4. 實驗對比：在特定任務上對比不同 Normalization 方法的效果

參考資料

  • Ioffe, S., & Szegedy, C. (2015). Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift.
  • Ba, J. L., Kiros, J. R., & Hinton, G. E. (2016). Layer Normalization.
  • Ulyanov, D., Vedaldi, A., & Lempitsky, V. (2016). Instance Normalization: The Missing Ingredient for Fast Stylization.
  • Wu, Y., & He, K. (2018). Group Normalization.

Overfitting 過擬合是甚麼？

發表於 2026-03-08 更新於 2026-08-16

什麼是過擬合（Overfitting）？

過擬合（Overfitting）是機器學習和深度學習中最常見的問題之一。它指的是模型在訓練數據上表現得非常好，但在新的、未見過的數據（測試數據或驗證數據）上表現卻很差的現象。

簡單來說，過擬合就是模型「記住」了訓練數據的細節和噪聲，而不是學習到數據背後的真實規律。

過擬合的直觀理解

想像你正在準備考試：

  • 正常學習（Good Fit）：你理解了課本的概念和原理，能夠靈活應用到新的題目上
  • 過擬合（Overfitting）：你把課本的所有題目和答案都背下來了，但遇到稍微不同的題目就不會做了
  • 欠擬合（Underfitting）：你只是粗略地瀏覽了課本，連基本概念都沒掌握

在機器學習中，過擬合意味著模型過度適應了訓練數據的特性，包括其中的噪聲和異常值，導致泛化能力變差。

如何判斷是否發生過擬合？

訓練曲線分析

最直接的方法是觀察訓練曲線：

  1. 訓練損失（Training Loss）持續下降
  2. 驗證損失（Validation Loss）先下降後上升

當驗證損失開始上升而訓練損失繼續下降時，就是過擬合的明顯信號。

性能指標對比

  • 訓練準確率 >> 驗證準確率：存在明顯的性能差距
  • 訓練準確率接近 100%，但驗證準確率很低：典型的過擬合

過擬合的原因

1. 模型複雜度過高

模型參數過多，表達能力太強，能夠記住訓練數據的所有細節。

例子：

  • 使用深度很深的神經網絡處理簡單任務
  • 使用高階多項式擬合少量數據點

2. 訓練數據不足

訓練樣本太少，無法充分代表真實數據的分布。

例子：

  • 只用 100 張圖片訓練一個複雜的圖像分類模型
  • 數據集類別不平衡

3. 訓練時間過長

模型訓練了太多輪（epochs），開始記憶訓練數據的噪聲。

4. 特徵過多

輸入特徵維度很高，但其中包含許多不相關或冗餘的特徵。

5. 缺乏正則化

沒有使用適當的正則化技術來約束模型的複雜度。

如何避免和解決過擬合？

1. 增加訓練數據

最根本的解決方法是獲取更多的訓練數據。

  • 收集更多真實數據
  • 使用數據增強（Data Augmentation）技術
    • 圖像：旋轉、翻轉、裁剪、調整亮度/對比度
    • 文本：同義詞替換、回譯（Back Translation）
    • 音頻：加入噪聲、改變速度、音調

2. 簡化模型

降低模型的複雜度，減少參數數量。

  • 減少網絡層數
  • 減少每層的神經元數量
  • 使用更簡單的模型架構

3. 正則化（Regularization）

通過在損失函數中添加懲罰項來約束模型複雜度。

L1 正則化（Lasso）

Loss=Lossoriginal+λ∑i∣wi∣Loss = Loss_{original} + \lambda \sum_{i}|w_i| Loss=Lossoriginal​+λi∑​∣wi​∣

  • 傾向於產生稀疏權重（許多權重變為 0）
  • 可以用於特徵選擇

L2 正則化（Ridge）

Loss=Lossoriginal+λ∑iwi2Loss = Loss_{original} + \lambda \sum_{i}w_i^2 Loss=Lossoriginal​+λi∑​wi2​

  • 傾向於使權重變小但不為 0
  • 最常用的正則化方法

4. Dropout

在訓練過程中隨機「丟棄」一部分神經元。

工作原理：

  • 訓練時：以概率 p 隨機將某些神經元的輸出設為 0
  • 測試時：使用所有神經元，但輸出乘以 (1-p)

效果：

  • 防止神經元之間產生複雜的共適應關係
  • 相當於訓練多個子網絡的集成

5. Early Stopping（早停）

監控驗證集的性能，當驗證損失不再下降時停止訓練。

實現步驟：

  1. 在每個 epoch 後評估驗證損失
  2. 如果驗證損失連續 N 個 epoch 沒有改善，停止訓練
  3. 使用驗證損失最低時的模型權重

6. Batch Normalization

標準化每一層的輸入，具有一定的正則化效果。

  • 加速訓練
  • 允許使用更大的學習率
  • 減少對初始化的敏感度
  • 具有輕微的正則化作用

7. Cross-Validation（交叉驗證）

更好地評估模型的泛化能力。

K-Fold Cross-Validation：

  1. 將數據分成 K 份
  2. 輪流使用其中一份作為驗證集，其餘作為訓練集
  3. 計算 K 次驗證結果的平均值

8. 集成學習（Ensemble Learning）

結合多個模型的預測結果。

  • Bagging：訓練多個模型，對結果取平均或投票
  • Boosting：順序訓練多個模型，後面的模型專注於前面模型的錯誤
  • Stacking：使用一個元模型來組合多個基礎模型的預測

9. 特徵選擇

移除不相關或冗餘的特徵。

  • 相關性分析
  • 特徵重要性評估
  • 降維技術（PCA、t-SNE）

過擬合 vs. 欠擬合 vs. Good Fit

特性 欠擬合 Good Fit 過擬合
訓練誤差 高 低 很低
驗證誤差 高 低 高
模型複雜度 太低 適中 太高
泛化能力 差 好 差
解決方法 增加模型複雜度 - 正則化、更多數據

實際應用案例

案例 1：圖像分類

問題：使用 ResNet-152 訓練只有 1000 張圖片的數據集，訓練準確率 99%，驗證準確率 60%。

解決方案：

  1. 使用數據增強（旋轉、翻轉、裁剪）
  2. 改用較淺的網絡（ResNet-18 或 ResNet-34）
  3. 使用預訓練模型並凍結大部分層
  4. 添加 Dropout 層
  5. 使用 Early Stopping

案例 2：文本分類

問題：LSTM 模型在訓練集上準確率 95%，測試集上只有 70%。

解決方案：

  1. 增加訓練數據
  2. 減少 LSTM 層數或隱藏單元數
  3. 添加 Dropout（recurrent dropout）
  4. 使用 L2 正則化
  5. 限制詞彙表大小

Bias-Variance Trade-off（偏差-方差權衡）

過擬合與欠擬合的本質是偏差和方差的權衡問題。

  • Bias（偏差）：模型預測的期望值與真實值之間的差距

    • 高偏差 → 欠擬合
    • 模型過於簡單，無法捕捉數據的規律

  • Variance（方差）：模型預測值的變化程度

    • 高方差 → 過擬合
    • 模型對訓練數據過於敏感

目標：找到一個平衡點，使得總誤差（偏差² + 方差 + 噪聲）最小。

總結

過擬合是機器學習中需要時刻警惕的問題。關鍵點：

  1. 監控訓練和驗證性能的差距，及時發現過擬合
  2. 優先考慮增加數據和數據增強
  3. 使用正則化技術（L1/L2、Dropout、Batch Normalization）
  4. 模型複雜度要與數據量匹配
  5. 使用 Early Stopping 防止過度訓練
  6. 交叉驗證確保模型泛化能力

記住：一個好的模型不是在訓練集上表現最好，而是在未見過的數據上表現穩定可靠。

2026-02-26-模型訓練方法介紹

發表於 2026-02-26 更新於 2026-08-16

深度學習模型訓練方法整理：DDP、DP 與 Gradient Accumulation

在實務訓練深度學習模型時，單張 GPU 往往無法滿足速度或記憶體需求。因此我們會透過平行化訓練與梯度技巧來優化效率與穩定性。

這是最原始的訓練方法，資料會先被分成多個 mini-batch，訓練後更新模型權重，以此反覆。

本文整理三種常見方法：

  • DDP（Distributed Data Parallel）
  • DP（Data Parallel）
  • Gradient Accumulation

一、DDP（Distributed Data Parallel）

概念

DDP 是目前主流的多 GPU 訓練方式，廣泛使用於大型模型訓練中。
在很多大型模型或是資料集非常大量的時候非常有用(節省n個GPU的訓練時間)。

運作原理是建立多個Process，每個Process對應一張GPU，並且在每個Process中複製一份模型。每個Process負責處理不同的資料子集，並且在每次反向傳播後使用All-Reduce來同步梯度，確保所有模型複本的權重保持一致。

這種方式可以跨主機訓練，適合大規模分布式訓練。

題外話: 研究生時期瀏覽了很多開源模型，發現有些專案雖然表明使用DDP但實際上是使用DP，這種情形會導致訓練時雖然主機有N張GPU但實際上只有1張GPU在訓練。

運作方式

  1. 在每個 GPU 上 複製一份模型
  2. 將資料分成不同 mini-batch 分配給各 GPU
  3. 每個 GPU 各自計算梯度
  4. 使用 All-Reduce 同步梯度
  5. 同步更新全部模型複本，保持所有模型起始訓練時的權重一致

梯度是如何跨主機同步的？

DDP 使用了分布式通信協議(NCCL、Gloo)來實現跨主機的梯度同步，這是一種專為訓練設計的Socket技術(就是網路通訊)。

因為NCCL或Gloo會開啟Port來傳輸資料，因此有時候發生NCCL或Gloo的Port被佔用的情況，就會發生訓練錯誤。

二、DP（Data Parallel）

概念

DP 也是常見的訓練方式。與 DDP 不同的是，DP 限制在單主機內的多 GPU 訓練，無法跨主機訓練。

運作方式

  1. 在多個 GPU 上複製相同模型
  2. 將資料分成多個 mini-batch 分配給各 GPU
  3. 每個 GPU 各自計算梯度
  4. 主 GPU 收集所有 GPU 的梯度，進行平均
  5. 將梯度彙總到主 GPU 統一更新

DP 的實作相對簡單，但由於資料要先彙整到主GPU，因此主 GPU 可能成為瓶頸。

三、Gradient Accumulation

概念

當 GPU 記憶體不足以支撐大 batch size 時，可以使用梯度累積技巧。

運作方式

  • 將一個大 batch 拆成多個小 batch
  • 每次 forward/backward 只計算梯度
  • 不立即更新權重
  • 累積指定步數後再更新一次

為什麼有效？

大 batch size 通常有：

  • 更穩定的梯度
  • 較低的梯度噪聲
  • 更好的收斂特性

Gradient Accumulation 可以：

  • 在不增加顯存的情況下
  • 模擬更大的 batch size 效果

LLM 訓練需要的資料量非常大，通常只訓練 1 Epoch 就需要幾十萬甚至幾百萬的 batch size，因此梯度累積是必須的。

方法比較總整理

方法 適用情境 訓練速度 實作難度
DDP 模型大 + 資料大 超快 最難
DP 模型小 + 資料大 快 簡單(一行python就可以)
Gradient Accumulation 顯存不足 不提升速度 簡單

梯度是甚麼?

一句話解釋：
梯度就是每個神經元(參數)往"哪個方向調整"以及"要調整的幅度是多少"會讓損失函數增加最快？

在深度學習中，通常會沿著梯度的反方向更新參數，因為梯度指向損失函數增加最快的方向，所以我們要往相反的方向走，才能讓損失函數下降。

梯度（Gradient）雖然聽起來很專業，但其實就是我們在國中時期(應該是?)學到的斜率、速率的概念。在深度學習中，梯度用來指示損失函數(Loss function)相對於模型參數的變化率。

阿嬤教你梯度

阿嬤正走去早上的菜市場，阿嬤距離菜市場100公尺，花了20秒走到，假設阿嬤行走的速度不變，阿嬤的速度(速率)是多少？

上面的題目我們很容易的可以得到式子：

速度=100/20=5(公尺/每秒)速度 = 100 / 20 = 5(公尺/每秒) 速度=100/20=5(公尺/每秒)

速度 5(公尺/每秒) 的計算過程，類似於我們在深度學習中計算變化率的概念。
嚴謹地說：速度=距離對時間的變化率
所以梯度，就是變化率。

換到深度學習的領域就是：梯度=損失函數對參數的變化率
只是在深度學習中，我們的變數(參數)不只有一個，用阿嬤舉例就是：阿嬤可以同時往東西南北走、有上坡、下坡，梯度就會是一個向量，每個方向都有速度。

這個向量就類似這張表：

方向 東 西 南 北 上坡 下坡
速度(公尺/每秒) 5 -3 0 2 1 -5

這個 -4 告訴我們，當阿嬤以 5(公尺/每秒) 的速度行走時，如果她想要減少花費的時間，她應該增加她的速度。

所以就跟前面提到的，梯度指向損失函數增加最快的方向，因此沿著負梯度方向可以最快地降低損失。

[進階2]反向傳播（Backpropagation）

剛剛的阿嬤例子是單一參數的情況，在深度學習中，我們通常有成千上萬個參數需要更新，可以想像成是跑一個接力賽，每個跑者都需要知道自己應該往哪個方向跑，跑多快，這時候參數就會變多，這時候我們就需要用到反向傳播來計算這些參數的梯度。

由於每個參數會影響著下個參數，所以我們需要從最後一層開始，逐層往前計算每個參數的梯度，這樣才能確保每個參數都能正確地更新，而這就是反向傳播。

實際範例

假設一場 3000 公尺(ddd)接力賽，有 2 個跑者，每人跑 d2=1500\frac{d}{2} = 15002d​=1500 公尺：

  • 第一個跑者速度為 p1p_1p1​
  • 第二個跑者速度 p2=p1+2p_2 = p_1 + 2p2​=p1​+2（比第一個跑者快 2 公尺/秒）

目標函數(Loss)是總時間：

Loss(p1)=d2p1+d2p2=d2p1+d2(p1+2)Loss(p_1) = \frac{d}{2p_1} + \frac{d}{2p_2} = \frac{d}{2p_1} + \frac{d}{2(p_1+2)} Loss(p1​)=2p1​d​+2p2​d​=2p1​d​+2(p1​+2)d​

第二個跑者的梯度

最簡單的是第二個跑者的梯度(最後一個輸出層)：

d2p2\frac{d}{2p_2}2p2​d​ 只受到 p2p_2p2​ 影響，所以直接對 p2p_2p2​ 求導數，d2p1\frac{d}{2p_1}2p1​d​ 視為常數，直接消去。

∂Loss∂p2=∂∂p2(d2p2)=−d2p22\frac{\partial Loss}{\partial p_2} = \frac{\partial }{\partial p_2}\left(\frac{d}{2p_2}\right) = -\frac{d}{2p_2^2} ∂p2​∂Loss​=∂p2​∂​(2p2​d​)=−2p22​d​

第一個跑者的梯度

計算第一個跑者的梯度就比較難了，因為計算 ∂Loss∂p1\frac{\partial Loss}{\partial p_1}∂p1​∂Loss​ 時，需要考慮兩種影響：

  1. 直接影響(p1p_1p1​ 直接影響自己跑步時間)，也就是第一項：

∂∂p1(d2p1)=−d2p12\frac{\partial}{\partial p_1}\left(\frac{d}{2p_1}\right) = -\frac{d}{2p_1^2} ∂p1​∂​(2p1​d​)=−2p12​d​

  1. 間接影響(p1p_1p1​ 影響第二個跑者時間)，第二項：

這裡需要用到連鎖律(chain rule)，否則是沒辦法直接計算Loss對p1p_1p1​的變化率。
∂Loss∂p2⋅∂p2∂p1\frac{\partial Loss}{\partial p_2} \cdot \frac{\partial p_2}{\partial p_1}∂p2​∂Loss​⋅∂p1​∂p2​​ 可以理解成：Loss對p2p_2p2​的變化率，乘上p2p_2p2​對p1p_1p1​的變化率，就會是Loss對p1p_1p1​的變化率。

∂∂p1(d2p2)=∂Loss∂p2⋅∂p2∂p1=−d2p22⋅1=−d2p22\frac{\partial}{\partial p_1}\left(\frac{d}{2p_2}\right) = \frac{\partial Loss}{\partial p_2} \cdot \frac{\partial p_2}{\partial p_1} = -\frac{d}{2p_2^2} \cdot 1 = -\frac{d}{2p_2^2} ∂p1​∂​(2p2​d​)=∂p2​∂Loss​⋅∂p1​∂p2​​=−2p22​d​⋅1=−2p22​d​

總梯度

∂Loss∂p1=−d2p12−d2p22\frac{\partial Loss}{\partial p_1} = -\frac{d}{2p_1^2} - \frac{d}{2p_2^2} ∂p1​∂Loss​=−2p12​d​−2p22​d​

這個例子說明了反向傳播的核心：當參數之間有依賴關係時，必須從後往前計算，把所有影響路徑的梯度加總起來。在多層神經網絡中，這個過程會逐層往前傳遞，直到第一層為止。

ROC曲線詳解-機器學習模型評估的重要指標

ROC 指標介紹

圖片來源：https://www.nomidl.com/machine-learning/what-is-the-roc-curve/

ROC（Receiver Operating Characteristic）曲線是一種用於評估分類模型效能的指標，特別適用於 二分類問題。

ROC 曲線的橫軸是FPR（False Positive Rate），縱軸是TPR（True Positive Rate），也稱為召回率（Recall）。

  • TPR（真正率）= TP / (TP + FN)：模型成功預測為正例的比例。
  • FPR（假陽性率）= FP / (FP + TN)：實際為負例卻被錯誤預測為正例的比例。

ROC 曲線呈現模型在不同閾值（threshold）下的分類表現，曲線越靠近左上角，表示模型效能越好。

1x1 卷積層介紹

發表於 2025-05-01 更新於 2026-08-16

什麼是 1x1 卷積層？

1x1 卷積層是一種特殊的卷積操作，其中卷積核的尺寸為 1x1。這意味著每次卷積操作只會影響輸入特徵圖中的單個像素，但會跨通道進行計算。

1x1 卷積層的用途

1x1 卷積層在深度學習中有以下幾個主要用途：

  1. 降維或升維：通過調整輸出通道數，1x1 卷積層可以用於壓縮或擴展特徵圖的通道數，從而減少計算量或增加模型表達能力。
  2. 非線性映射：1x1 卷積層可以引入非線性激活函數（如 ReLU），從而增加模型的非線性表達能力。
  3. 特徵融合：通過跨通道的加權求和，1x1 卷積層可以實現不同通道特徵的融合。

1x1 卷積層等同於線性層(Linear)嗎?

讓我們來簡單寫個程式驗證一下這兩者是否相同:

一維的情況:

1x1 卷積層的數學表示

假設輸入特徵圖的尺寸為 ( H \times W \times C_{in} )，1x1 卷積層的輸出特徵圖尺寸為 ( H \times W \times C_{out} )。其計算公式為：

[
Y_{h,w,c} = \sum_{i=1}^{C_{in}} X_{h,w,i} \cdot W_{i,c} + b_c
]

其中：

  • Xh,w,iX_{h,w,i}Xh,w,i​ 是輸入特徵圖在位置 (h,w)(h, w)(h,w) 和第 iii 通道的值。
  • ( W_{i,c} ) 是 1x1 卷積核的權重。
  • ( b_c ) 是偏置項。
  • ( Y_{h,w,c} ) 是輸出特徵圖在位置 ( (h, w) ) 和通道 ( c ) 的值。

1x1 卷積層的優勢

  • 計算效率高：相比於更大的卷積核，1x1 卷積層的計算量更小。
  • 靈活性強：可以靈活調整通道數，適用於各種網絡結構。
  • 應用廣泛：在 GoogLeNet（Inception 模型）和 ResNet 等經典網絡中廣泛使用。

結論

1x1 卷積層是一種簡單但功能強大的卷積操作，能夠有效地提升模型的表達能力，同時降低計算成本。在設計卷積神經網絡時，合理使用 1x1 卷積層可以帶來顯著的性能提升。
