目標

既然我們已經有了模擬溫度感測器的 kernel module，並且可以透過 ioctl() 設定更新間隔，那麼接下來我們要做的是：將它註冊為 hwmon 感測器，讓 user-space 能透過標準的 sysfs 介面讀取溫度。

註冊為 hwmon 感測器，是為了讓 Linux 與上層軟體把它視為「標準硬體監控感測器」，而不是自訂的 /dev/virtual_sensor。

hwmon 是 Linux 的一個子系統，提供了統一的介面來讀取硬體監控感測器的資料，例如溫度、電壓、風扇轉速等。透過 hwmon，使用者程式可以不需要知道底層硬體的細節，就能讀取感測器資料。

與我們當前的差異是?

  • 目前： 你的程式必須知道 /dev/virtual_sensor 和自訂 ioctl 規格
  • hwmon：任何支援 Linux hwmon 的工具或服務，都能用標準方式讀溫度
