2026-08-01-RTOS複習 Part2

發表於 2026-08-01 更新於 2026-08-25

因為本人最近在求職，需要複習相關RTOS知識，所以整理了一些筆記，方便自己複習，也希望對其他人有幫助。

延續上篇 (Part1)，我們在上篇文章簡單架設了環境，並測試簡單的系統啟動時自動執行的程式來簡單驗證。

接下來要接觸有關 Driver 的部分。 QEMU 可以模擬一些硬體設備，像是 UART、網路卡、SD 卡等等，這些設備都可以透過 kernel module 來操作。

因此本 Part 會來簡單撰寫一個虛擬感測器 Driver，用來模擬溫度感測器。

Driver（驅動程式）是跑在 Linux kernel 內部 的程式，用來把硬體或虛擬裝置，提供成 user-space 可使用的標準介面。
一般程式 → 跑在 user space → 權限受限制 → 出錯通常只會讓該程式結束
Driver → *.ko → 跑在 kernel space → 可操作裝置、記憶體、interrupt、DMA 等底層資源 → 寫錯可能讓整台 Linux kernel crash

  • 和一般程式的差異： .c → 編譯＋連結 → ELF 執行檔 → Linux 用 ./program 啟動成一個行程

測試

然後透過這個 image 來啟動 QEMU，並在 QEMU 中載入模組。

  • insmod 是用來載入 kernel module 的指令
  • dmesg 是用來查看 kernel log 的指令，也就是程式碼中的 pr_info()
  • tail 是用來查看檔案最後幾行的指令

為甚麼要看 /dev/virtual_sensor 呢？因為我們在 module 中使用了 misc_register 來註冊一個 misc device，這個 device 會在 /dev 下建立一個檔案，名稱就是我們在 miscdevice 結構中指定的 name，也就是 virtual_sensor。

然後 cat 該路徑，就會呼叫我們在 module 中定義的 read() 函式，並回傳溫度資料。
