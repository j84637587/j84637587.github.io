各種 Normalization 介紹

發表於 2026-03-09 更新於 2026-08-16

什麼是 Normalization？

Normalization 是深度學習中常用的一種技術，用於標準化神經網絡中的數據分布。它可以加速模型訓練、提高模型穩定性，並在某些情況下提升模型性能。

用另一種方式來說明，假設你有1000張黑狗的圖片，你要讓模型學習分辨圖片是黑狗的圖片，而不是白狗、貓…等。
而此時，會發現雖然這些圖片都是黑狗，但每張圖片的背景、光線、角度…等都不一樣，這些因素會影響模型的學習效果。
Normalization 就是用來解決這些問題的技術，通過對數據進行標準化，使得模型能夠更好地學習到黑狗的特徵，而不受其他因素的干擾。
而這些事情都是在向量空間中進行的，實際上標準化是透過數學公式取得這1000張圖片的平均值和標準差。

為什麼需要 Normalization？

在深度神經網絡的訓練過程中，每一層的輸入分布會隨著前面層的參數更新而不斷變化，這種現象稱為「內部協變量偏移」（Internal Covariate Shift）。Normalization 技術通過標準化每一層的輸入，可以：

  1. 加速訓練：減少內部協變量偏移，使得模型能夠使用更大的學習率
  2. 提高穩定性：降低梯度消失和梯度爆炸的風險
  3. 正則化效果：某些 Normalization 方法具有一定的正則化作用，可以減少過擬合

常見的 Normalization 方法

1. Batch Normalization (BN)

Batch Normalization 是最常用的正規化方法之一，由 Ioffe 和 Szegedy 在 2015 年提出。

工作原理：

  • 對每個 mini-batch 中的數據，在每個特徵維度上計算均值和方差
  • 使用這些統計量來標準化數據
  • 引入可學習的縮放參數 γ 和偏移參數 β

公式：

x^=x−μBσB2+ϵ\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} x^=σB2​+ϵ​x−μB​​

y=γx^+βy = \gamma \hat{x} + \beta y=γx^+β

適用場景：

  • CNN 中使用廣泛
  • batch size 較大時效果較好
  • 訓練和推理階段行為不同（推理時使用移動平均的統計量）

優點：

  • 顯著加速訓練
  • 允許使用更大的學習率
  • 降低對初始化的敏感度

缺點：

  • 對 batch size 敏感，batch size 太小時效果不佳
  • 在 RNN 等序列模型中使用較困難

2. Layer Normalization (LN)

Layer Normalization 由 Ba 等人在 2016 年提出，主要用於解決 Batch Normalization 在小 batch size 和序列模型中的問題。

工作原理：

  • 對每個樣本的所有特徵維度計算均值和方差
  • 不依賴 batch size，在每個樣本內部進行標準化

公式：

x^=x−μLσL2+ϵ\hat{x} = \frac{x - \mu_L}{\sqrt{\sigma_L^2 + \epsilon}} x^=σL2​+ϵ​x−μL​​

y=γx^+βy = \gamma \hat{x} + \beta y=γx^+β

適用場景：

  • RNN、LSTM、Transformer 等序列模型
  • batch size 較小的情況
  • 強化學習

優點：

  • 不受 batch size 影響
  • 訓練和推理階段行為一致
  • 適合序列模型

缺點：

  • 在某些 CNN 任務中效果可能不如 Batch Normalization

3. Instance Normalization (IN)

Instance Normalization 由 Ulyanov 等人在 2016 年提出，主要用於風格遷移任務。

工作原理：

  • 對每個樣本的每個通道分別計算均值和方差
  • 在空間維度上進行標準化

適用場景：

  • 圖像風格遷移
  • 圖像生成任務（GAN）
  • 不希望不同樣本之間相互影響的場景

優點：

  • 適合處理單個樣本的風格信息
  • 對 batch size 不敏感

缺點：

  • 在一般的分類任務中效果不如 Batch Normalization

4. Group Normalization (GN)

Group Normalization 由 Wu 和 He 在 2018 年提出，作為 Batch Normalization 的替代方案。

工作原理：

  • 將通道分成多個組
  • 在每個組內計算均值和方差
  • 是 Layer Normalization 和 Instance Normalization 的推廣

適用場景：

  • batch size 較小的情況
  • 目標檢測、圖像分割等任務
  • 替代 Batch Normalization

優點：

  • 不受 batch size 影響
  • 在小 batch size 時效果優於 Batch Normalization
  • 在計算機視覺任務中表現良好

缺點：

  • 需要選擇合適的分組數量

各種 Normalization 的比較

方法 標準化維度 Batch Size 敏感度 主要應用場景
Batch Normalization 跨 batch 樣本 高 CNN、大 batch size
Layer Normalization 跨特徵維度 低 RNN、Transformer
Instance Normalization 單個樣本的單個通道 低 風格遷移、GAN
Group Normalization 通道分組 低 小 batch size、檢測任務

如何選擇 Normalization 方法？

  1. CNN + 大 batch size：優先選擇 Batch Normalization
  2. RNN、Transformer 等序列模型：選擇 Layer Normalization
  3. 小 batch size 的計算機視覺任務：選擇 Group Normalization
  4. 風格遷移、圖像生成：選擇 Instance Normalization
  5. 強化學習：選擇 Layer Normalization

實踐建議

  1. 初始選擇：對於大多數 CNN 任務，先嘗試 Batch Normalization
  2. 調整位置：Normalization 層通常放在卷積層之後、激活函數之前
  3. 微調參數：注意調整 momentum 參數（用於計算移動平均）
  4. 實驗對比：在特定任務上對比不同 Normalization 方法的效果

參考資料

  • Ioffe, S., & Szegedy, C. (2015). Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift.
  • Ba, J. L., Kiros, J. R., & Hinton, G. E. (2016). Layer Normalization.
  • Ulyanov, D., Vedaldi, A., & Lempitsky, V. (2016). Instance Normalization: The Missing Ingredient for Fast Stylization.
  • Wu, Y., & He, K. (2018). Group Normalization.
